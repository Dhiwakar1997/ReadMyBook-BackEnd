Stage 1 — Document Upload
1
Client → POST /documents
  • Sends display_name size_in_kb
  • Receives document_id upload_url (Azure SAS, 15 min expiry)
2
API Server — DocumentService
  • Create Document record (status = new)
  • Generate ULID-based ID: doc_<ULID>
  • Create DocumentAccess (owner link)
  • Generate Azure SAS upload URL → pdfs/{doc_id}/{doc_id}.pdf
3
Client Uploads PDF → Azure Blob Storage
  • Direct upload to signed SAS URL (bypasses API server)
  • Blob path: pdfs/{doc_id}/{doc_id}.pdf
  • Azure Event Grid fires BlobCreated event
  • Event pushed to Azure Queue as base64-encoded JSON message
Worker polls Azure Queue (5s interval)
Stage 2 — Initial Batching
4
Worker — Download & Hash
  • Download PDF from Azure Blob to local disk
  • Compute SHA-256 file hash for deduplication
  • Set document status = processing, job = batching
Pre-Dedup Check
file_hash exists in
original_documents?
Duplicate Found
Link to existing OriginalDocument → increment reference_counter → copy metadata → set status = active → delete PDF blobs → skip entire pipeline
Unique — Continue Pipeline
Proceed to PDF splitting and batch processing below
5
PDF Batch Splitting
  • Split PDF into N batches of 10 pages each
  • Create DocumentBatch records (status = pending)
  • Upload each batch PDF to pdfs/{doc_id}/batches/batch_N.pdf
  • Each upload triggers a new BlobCreated queue event
  • Set job status = processing
N batch events queued — processed in parallel
Stage 3 — Batch Conversion (per batch)
6
marker-pdf Conversion
  • Download batch PDF from blob
  • Run marker_single CLI → generates Markdown + metadata JSON + images
  • Rename images with batch prefix: batch_N_filename.jpg
  • Rewrite image links in markdown
7
Upload Batch Results
  • Upload images → images/{doc_id}/batch_N_*.jpg
  • Upload markdown → markdowns/{doc_id}/batch_N.md
  • Upload metadata → markdowns/{doc_id}/batch_N.json
  • Adjust page_ids with batch offset
  • Update DocumentBatch status = completed
  • Increment completed_batches counter — check if all done
All batches completed → trigger Final Merge
Stage 4 — Merge, Enrichment & Embedding
8
Merge Batches
  • Download all batch markdowns + metadata JSONs
  • Concatenate markdowns in order (batch_1 + batch_2 + ...)
  • Merge metadata: headings, chapters, TOC, page mappings
  • Generate enhanced metadata: content_ids, heading counts
LLM Enrichment (GPT-4)
a
Chapter Detection
Identify book structure, assign chapters to headings
b
Summary & Title
Generate book title and summary from metadata
c
Category Classification
Classify into single category (Science, Fiction, etc.)
d
Sub-Categories
Assign multiple tags based on content
9
Vector Embedding → Qdrant
  • Embed all content sections with text-embedding-3-large (3072-dim)
  • Generate BM25 sparse vectors via FastEmbed
  • Store hybrid vectors in Qdrant (dense + sparse with RRF fusion)
  • Payload includes og_doc_id for dedup linking
10
Upload Final Artifacts
  • Upload merged markdown → markdowns/{doc_id}/{doc_id}.md
  • Upload metadata JSON → markdowns/{doc_id}/{doc_id}.json
  • List and store image filenames in Document.images
Stage 5 — Post-Dedup & Finalize
Post-Dedup Check
Re-check file_hash
after processing
Duplicate Found (race condition)
Link to existing OriginalDocument → delete Qdrant vectors → delete all blobs → copy metadata from og_doc
New Unique Document
Create OriginalDocument (og_doc_<ULID>) → copy blobs to og_doc archive paths → reindex vectors with og_doc_id → delete doc-specific blobs
11
Finalize Document
  • Update Document: status = active, job = completed
  • Set generated_title, display_name, category, sub_categories
  • Update Redis cache: doc metadata (5d TTL), doc images
  • Deduct billing: conversion time + LLM enrichment + embedding costs
  • Clean up local temp files
Fallback — Mathpix OCR (on 3x batch failure)
!
Trigger Condition
Batch conversion fails 3 times (dequeue_count ≥ 3) → route to Mathpix async pipeline
↻
Mathpix Async Pipeline
  • Submit: Upload PDF to Mathpix API → receive pdf_id
  • Poll: Async non-blocking status poll (5s interval, semaphore = 3 concurrent)
  • Download: Fetch md.zip → extract markdown + images
  • Post-process: Same as marker pipeline — metadata, enrichment, embedding
  • Billing: Mathpix per-page cost + LLM + embedding costs
  • Cleanup: Delete pdf_id from Mathpix servers, remove temp files
