Ask AI Graph LangGraph RAG
4-node pipeline: query refinement → conditional RAG retrieval → category-aware response → evaluation
▶ START — User Query
POST /documents/{id}/ask/stream
1
query_refiner
GPT-4.1-mini • temp=0
  • Extract last 6 messages for chat context
  • Structured output: refined_query user_query_language chat_summary
  • Classify intent: is_followup requires_deep_analysis is_unclear
  • Dynamic top_k: deep_analysis=15, followup=10, default=5
query_refiner_router
is_unclear = true
Return warm refusal message → END
is_followup = true
Needs broader context → rag_retrieval_agent
new query
Try with current context first → chat_agent
2
rag_retrieval_agent
Qdrant Hybrid Search
  • Dense: text-embedding-3-large (3072-dim, COSINE)
  • Sparse: FastEmbed BM25 for keyword matching
  • Fusion: Reciprocal Rank Fusion (RRF) of dense + sparse scores
  • Filter: Single doc by og_doc_id or multi-doc by accessible doc list
  • Returns formatted context with page numbers and content indices
rag_context injected into state
3
chat_agent
GPT-4.1 • category-aware temp
  • Select category-specific persona, temperature, and response style
  • Build prompt with: full_context active_context rag_context response_language
  • Async streaming generation with sentence-level buffering
  • Second structured call extracts: reference_contents (top 5, >80% confidence) + is_refusal

Word Explanation Graph LangGraph
2-node pipeline: context-based word explanation with optional RAG fallback
▶ START — Word/Phrase Selection
POST /documents/{id}/explain-word/stream
1
word_explanation_agent
GPT-4.1 • temp=0.2 • max=250 tokens
  • Build prompt with full_context active_context word_to_explain
  • Explain word/phrase strictly from document context
  • Use simple, accessible language
  • Async streaming generation
  • Structured extraction: reference_contents (up to 5 sources) + is_refusal
word_callback_router
refusal + no rag_context
Insufficient context → rag_retriever
success or already tried rag
Explanation generated → END
2
rag_retriever
Qdrant • alpha=0.3 • top_k=20
  • Embed the word/phrase itself (not a question)
  • alpha=0.3 favors BM25 sparse search for exact term matching
  • top_k=20 for broader context retrieval
  • Hybrid dense + sparse fusion via RRF
  • Format retrieved context and inject into state
retry word_explanation_agent with rag_context
↻
word_explanation_agent (retry)
GPT-4.1 • temp=0.2
Re-runs with enriched context from RAG retrieval. If still a refusal → returns refusal to user.
